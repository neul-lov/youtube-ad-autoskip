# YouTube 광고 자동스킵 유저스크립트

YouTube에서 광고가 나오면 자동으로 음소거하고 빨리감기·스킵한 뒤, 광고가 끝나면 소리와 재생 속도를 원래대로 되돌리는 유저스크립트입니다.

## 동작 방식

- 플레이어의 광고 상태(`ad-showing`) 변화와 영상 이벤트를 감지해 광고가 시작되는 즉시 반응합니다. 창이 백그라운드에 있어도 늦어지지 않습니다.
- 광고 중에는 음소거하고, 재생 속도를 16배로 올리고, 광고 끝으로 이동하며, 스킵 버튼이 있으면 누릅니다.
- 화면 위에 뜨는 배너 광고는 닫기 버튼을 누릅니다.
- 광고가 끝나면 광고 전의 음량, 음소거 상태, 재생 속도를 복구합니다.

외부 서버와 통신하지 않고, 어떤 데이터도 수집하거나 저장하지 않습니다.

## 설치 (macOS Safari)

1. Mac App Store에서 무료 앱 **Userscripts**를 설치하고 한 번 실행합니다.
2. Safari → 설정 → 확장 프로그램에서 Userscripts를 켭니다.
3. Safari 툴바의 Userscripts 아이콘 → "Open Extension Page" → **+** → "Create JS"를 누릅니다.
4. 기본 내용을 지우고 [`youtube-adskip.user.js`](youtube-adskip.user.js) 내용을 붙여넣은 뒤 저장합니다.
5. YouTube를 새로고침하고, 사이트 접근 허용을 묻는 창이 뜨면 허용합니다.

"Dock에 추가"로 만든 Safari 웹 앱에서 쓰려면 웹 앱 메뉴의 설정 → 확장 프로그램에서도 Userscripts를 켜 주세요.

Chrome·Firefox에서는 Tampermonkey나 Violentmonkey 같은 유저스크립트 확장에 같은 파일을 추가하면 됩니다.

## 한계

- YouTube가 화면 구조를 바꾸면 동작하지 않을 수 있습니다.
- 광고를 영상 스트림 안에 직접 넣는 방식의 광고에는 빨리감기가 통하지 않을 수 있습니다.

## 고지

- 이 프로젝트는 YouTube 및 Google과 관련이 없으며, 이들의 승인이나 후원을 받지 않았습니다. "YouTube"는 Google LLC의 상표입니다.
- 광고 차단·우회는 YouTube 서비스 약관에 어긋날 수 있습니다. 사용에 따른 책임은 사용자에게 있습니다.
- 광고 없이 백그라운드 재생 등을 원하시면 YouTube Premium을 이용해 크리에이터를 지원하는 것도 고려해 주세요.
